# 🎓 Smart Attendance System

## 📌 Description
A Python-based Smart Attendance System that helps manage student attendance efficiently. It allows users to register students, log in, record attendance, and view attendance reports.

## ✨ Features
- Student Registration
- User Login
- Record Attendance
- View Attendance Records
- Generate Attendance Report

## 🛠️ Technologies Used
- Python
- SQLite

## 📂 Project Files
- app.py
- database.py
- register.py
- login.py
- attendance.py
- report.py
